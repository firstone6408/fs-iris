# fs-iris

> An AI companion platform with voice, vision, memory, and a 3D avatar.

## Overview

**fs-iris** is the core AI system of the Iris ecosystem.

The goal of this project is to build a natural AI companion capable of:

- 💬 Natural conversation
- 🎤 Speech recognition (STT)
- 🔊 Text-to-speech (TTS)
- 🧠 Local LLM inference
- 💾 Long-term memory
- 👀 Vision and face recognition
- 🧍 Real-time 3D avatar
- 🔧 Tool calling
- 🌐 Integration with other Iris modules

## Ecosystem

- `fs-iris` — Core AI companion
- `fs-iris-observer` — Device and sensor integration
- `fs-iris-translator` — AI translation service
